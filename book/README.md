# 摄影大师画廊 · 书稿

> 以信息梳理的方式，为每位摄影大师写一篇短文：生平、历史背景、拍摄方式、技术特点、代表作品、成就、在摄影史的位置。
> 目标：形成一本可以出版的中文书稿。

## 结构

书稿按主题分七个章节，每章一位摄影师一篇：

| 章节 | 主题 | 收录 |
|------|------|------|
| [01-街头的等待](01-街头的等待/) | 街头摄影 | 布列松、何藩、森山大道、Alex Webb、Garry Winogrand 等 |
| [02-纪实的重量](02-纪实的重量/) | 纪实/战争/社会 | 卡帕、Lange、W. Eugene Smith、Susan Meiselas 等 |
| [03-房间里的人](03-房间里的人/) | 肖像 | Avedon、Penn、Newman、Platon 等 |
| [04-时尚的剧场](04-时尚的剧场/) | 时尚 | 牛顿、Bourdin、Lindbergh、Meisel 等 |
| [05-风景的秩序](05-风景的秩序/) | 风景/建筑 | Ansel Adams、Gursky、Becher 夫妇、Sugimoto 等 |
| [06-先锋与实验](06-先锋与实验/) | 实验/观念 | Man Ray、Moholy-Nagy、Cindy Sherman、Thomas Ruff 等 |
| [07-自然与远方](07-自然与远方/) | 野生动物/探险 | Steve McCurry、Frans Lanting、Jimmy Chin 等 |

## 单篇格式

每篇固定结构：

```
# 摄影师名（生卒年）：定位一句话

### 生平
### 历史背景
### 拍摄方式
### 技术特点
### 代表作品
### 成就
### 在摄影史的位置
```
